- 抽屉（`client/client.js`）读 `GET /api/memento/stats`（**路由已就绪**，返回 `stats` ＋ 渲染好的 `lines`）。

- 纯读；面板「只读」纪律不变（不改记忆内容）。

## 2. 「整理全库」按钮（排队式）

规格 3.5.9 原话：点一下即登记「待整理」，空闲时自动跑，跑完给回执。**受审计红线约束**，这里落成：

```
点击按钮
  → POST /api/memento/tidy-request  （登记一条「待整理」，只写标记、不调模型、不碰记忆）
  → 下次会话开场：预热段末行提示模型「用户点过全库整理，请跑一次 memory tidy（全库）」
  → 模型跑完 tidy 全库 → 清标记 → 审计留痕
```

- **存储**：新表 `tidy_requests(id, created_at, status)`（或复用等价的单行标记）；登记/清除都走 `MemoryProtocolCore`，**过审批门**（用户自己的动作，`writePolicy=auto` 即静默放行）。
- **路由**：`GET/POST /api/memento/tidy-request`，走 `ctx.connection.fetch`（栅栏纪律）。
- **提示**：预热段末行（与 S4b-6 的一行目录同处）追加一句；**只提示，不自动跑**。
- **回执**：跑完写 `audit(action='consolidation')`，面板可查。
