## 2. 设计

### A1 查询分词 `tokenize(text)`

零依赖、CJK 感知：

```
tokenize(text):
  norm = text.toLowerCase()
  把 norm 切成连续「字母/数字」段（正则 /[\p{L}\p{N}]+/gu）
  对每一段：
    含 CJK 字符（/[\u3400-\u9fff\uf900-\ufaff]/）：
      长度 1 → 整段作为一个词元
      否则    → 相邻二字滑窗（bigram）：seg[i..i+2]
    否则（纯拉丁/数字）：
      整段作为一个词元
  去重 → 词元数组
```

- **为什么 bigram**：中文无空格，且架构决策 10 已否决 FTS5（trigram 无法索引单字 CJK）。相邻二字滑窗是不依赖分词库的可行折中。
- **空查询 / 无词元**：返回空数组，由调用方（A2）处理。

### A2 多词召回

- 候选 = **任一词元命中**（`text.includes(token)`）的并集，外加「整串命中」。
- 相对旧行为的改变：由「整串必须整体出现」放宽为「命中任一词元即进候选」。
- 无词元（空查询）→ 返回空数组（与旧行为一致，不返回全量）。

### A3 相关度打分

对每个候选条目 `entry`，给定词元集 `tokens` 与原始查询 `rawQuery`：

```
text       = entry.text.toLowerCase()
hits       = tokens 中满足 text.includes(t) 的词元
coverage   = hits.length / tokens.length                 // 命中词元覆盖率
weighted   = Σ(len(t) for t in hits) / Σ(len(t) for t in tokens)   // 长词更具体，权重更高
exactBonus = text.includes(rawQuery.toLowerCase()) ? 0.2 : 0        // 整串精确命中加成
relevance  = min(1.0, 0.5 * coverage + 0.3 * weighted + exactBonus)
```

- 权重（0.5 / 0.3 / 0.2）为**可调默认**，实现时集中写在一处常量，便于日后调。
- `relevance ∈ [0, 1]`。

### A4 融合排序

```
sort: relevance DESC → recallCount DESC → updatedAt DESC → id ASC
```

- 保留原 `rankOrder` 作为**次级比较器**（热度和新旧退居 tie-break），改动最小、可解释。
- 相关度相同的条目，仍按旧规矩排（召回次数 → 更新时间 → id），保证稳定。

### A5 载体与接线

1. **新增类** `KeywordRetriever`（`lib/retrieval.mjs`）：
   - `id = 'keyword'`，`kind = 'substring'`（`Registry` 只允许 `'substring' | 'vector'`，keyword 是子串语义的超集）
   - `name` / `description`：一句话说明「分词＋多词＋相关度排序」
   - `retrieve(query, entries)`：实现 A1–A4，返回按相关度降序的**全部命中**（不截断，调用方自行 slice）
2. **默认装配**（`index.mjs`）：
   - `live.retriever` 初值由 `null` 改为 `new KeywordRetriever()`
   - `retrieval.vector=true` 且探测到 embedding 时，仍**换** `VectorRetriever`（keyword 退场）；vector 关闭/降级时回落到 keyword（不再回落 null）
   - 装配处：apply 初始装配 ＋ settings `onChange` 分支（`index.mjs:1110-1124`），两处都要改
3. **保留** `SubstringRetriever`：仍注册（`index.mjs:1217`），供对照、MCP（`mcp.test.mjs` 直接用 `new SubstringRetriever()`）与第三方
4. **类型注解**：`live.retriever` 相关 JSDoc（`index.mjs:938`、`:1320` 等）同步为「keyword 或 vector 检索器，非空」
