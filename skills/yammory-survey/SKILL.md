# 画像问卷（yammory-survey）

把用户口头讲的自己，变成 yammory_system 里可注入的画像：**七面条目（`memory` 工具）＋ 分领域知识水平（`memory_profile` 工具）**。

问卷的价值在于结构。它问的是「你的画像缺哪一块」，不是「我想知道什么」。

## 何时启动

**只由用户主动发起。** 触发词（任一）：

- 「做画像问卷」「开始问卷」「问我几个问题」
- 「更新画像」「补一下我的画像」「你对我了解多少，问我」
- 「yammory survey」

不启动的情形：用户只是在聊天里提到自己；用户没要求而你「觉得该多了解他一点」；用户在做别的事。**模型不得自作主张开问卷**——用户没答完的问卷比没有更糟，它留下半张脏画像。

用户中途喊停（「先到这」「够了」），立刻停，把已答的写进去，别追问。

## 一轮的形状

```
读现有画像  →  挑 1–3 个空白/陈旧的面  →  逐题问（一次一题）  →  每题落库  →  收尾报告
```

### 第 0 步：先读，再问

两个读操作都免费（无审批）：

```
memory        { action: 'query', track: 'user', scope: 'user-global', limit: 100 }
memory_profile{ action: 'list' }
```

从 `query` 的结果里看 **`facet` 字段**：哪些面已有条目、哪些面是空的。看 `tags`：带 `questionnaire` 的是上次问卷写的。看 `text`：内容是否已过时（工具不返回时间戳，「陈旧」靠内容自判——写着「在学 X」而用户已经换了方向，那就是陈旧）。

`memory_profile` 的 `list` 给出已打分的领域与档位；**没出现的领域就是空白**。

### 第 1 步：挑焦点

- **空白面优先**，陈旧面次之。
- 一轮 **1–3 个面**，别贪心。问卷是长跑，用户每次只愿意花几分钟。
- 挑完先告诉用户这一轮聊什么（一句话），再开始问。

### 第 2 步：逐题问

题库在 [`references/question-bank.md`](./references/question-bank.md)，按 7 面 × 24 子板块组织。

- **一次只问一题**，等用户答完再问下一题。不要一口气列 8 个问题——那是表格，不是对话。
- **能力/偏好类用选择题**（3–5 个选项 + 「说不准 / 其它」），选项直接映射到档位或类别，用户点一下就能答。
- **经历/事实类用问答题**，一次问一件事。
- 用户答得含糊（「还行」「一般」）就顺着追一句具体化，别硬套档位；实在问不出来就跳过，**空白比错值好**。
- 用户说「不知道 / 不想说」就跳过，记下这个板块没问到，别绕回来再问。

### 第 3 步：边答边写

用户答完一题就写一题（而不是攒到最后），这样中途喊停也不丢数据。写入协议见下节。

### 第 4 步：收尾

一轮结束后给一句话报告：这轮写了哪些面、几条条目、哪些领域打了分；再说下一轮可以聊哪几个面。不要复述用户的原话，也不要给「人格总结」。

## 写入协议

### 条目 → `memory` 工具

```
memory {
  action: 'add',
  track: 'user',            // 画像一律 user 轨
  scope: 'user-global',     // 跨工作区
  facet: '<七面之一>',       // 见下方「面 ↔ 板块」表
  tags: ['<板块名>', 'questionnaire'],
  text: '<周级、能力层的一句概括>'
}
```

`text` 是**概括条目**，不是用户原话，也不是对话记录。一条一个意思。

```jsonc
// 好
{ "text": "会 Python 与 TypeScript，能独立写中小型工具；Rust 只读得懂", "facet": "能力与技能", "tags": ["专业能力", "questionnaire"] }
{ "text": "作息偏夜猫子，凌晨 1–2 点睡、9 点起，周末补觉", "facet": "躯体", "tags": ["睡眠与饮食节律", "questionnaire"] }

// 坏——原话搬运、无概括、混了多个板块
{ "text": "用户说：'我一般吧，写代码还行，不过数学不太行，最近在学 Rust，睡得很晚，昨天三点才睡'" }
```

### 知识水平 → `memory_profile` 工具

「知识与学科水平」这个板块的答案，落进结构化的 profile 表，**不要**写成条目去充当标尺：

```
memory_profile { action: 'set', domain: '<31 个子领域之一>', level: <1..10> }
```

档位尺（`level` 缺省由 `tierForLevel` 推导，一般不用传 `tier`）：

| level | 档位 | 含义 |
|---|---|---|
| 1–3 | 科普 | 听得懂科普，不深入 |
| 4–6 | 本科 | 常用概念清楚，能跟上正常讨论（**默认锚点**） |
| 7–8 | 硕士 | 术语自由，能深入细节 |
| 9–10 | 专家 | 行话缩写自由，能讨论边界与不确定 |

`domain` 必须是 31 个子领域之一（`lib/constants.mjs` 的 `KNOWLEDGE_DOMAINS`），例如：中文 / 英语 / 数学 / 统计与概率 / 物理 / 化学 / 生物与医学 / 计算机与编程 / AI 与数据 / 历史 / 哲学 / 经济与金融 / 心理与教育 / 文学 / 音乐 / 美术与设计 / 影视与游戏 / 健康与养生 / 饮食与烹饪 / 理财与消费 / 人际与沟通 / 学习方法 / 信息检索与辨别 / AI 与工具使用。

用户只说了几个领域就写几个，**不要为了凑满 31 项替他打分**。

### 关于审批

`memory` 的写与 `memory_profile` 的 `set` 都过审批门（策略由部署配置决定）。审批被拒时，如实告诉用户哪一条没写进去，**不要**换措辞重试、不要绕过。

## 面 ↔ 板块对照（写 `facet` 用）

问卷合法的板块共 **24 个**（七面合计 29 个子板块，剔除 5 个仅观察面后为 24；「31」是知识领域数，不是子板块数）。

| facet | 问卷合法子板块 |
|---|---|
| 躯体 | 生理与健康 / 睡眠与饮食节律 / 感官与身体条件 |
| 心智 | 认知能力 / 知识与学科水平（→ `memory_profile`） |
| 价值与意愿 | 三观与信仰 / 道德与伦理立场 / 动机与长期目标 / 兴趣与审美偏好 |
| 能力与技能 | 专业能力 / 通用技能 / 学习能力与学习模式 / 身体技能 |
| 行为与习惯 | 日常作息与生活节律 / 工作与学习习惯 / 协作与交互偏好 |
| 社会与处境 | 社会关系 / 社会身份与角色 / 文化与人际处境 / 资源条件 |
| 经历与轨迹 | 成长与生活经历 / 教育与科研与工作经历 / 项目与作品史 / 成就挫折与转折 |

### 不问的 5 个板块（仅观察，S4 通道）

**思维方式与思辨 · 人格特质 · 情绪模式与心理强度 · 自我认知 · 决策与行动风格**

自陈在这五处最不可靠：人看不见自己的思维盲区、气质与情绪模式，对「我怎么决策」的叙述常与行为相反。它们留给后台观察通道，**不出现在问卷题目里**。

例外：用户**主动**聊到这五处（不是被你问出来的），照常记录，`facet` 照填——用户主动说的自陈也是数据，只是不作为问卷题目去索取。

## 颗粒度纪律（红线）

问卷问的是**周级、能力层的概括**。以下问法一律禁止：

| 禁止 | 为什么 | 改成 |
|---|---|---|
| 「你最近一天吃了什么」 | 日流水，明天就过期 | 「你平时吃饭大概怎么解决（自己做 / 外卖 / 食堂）」 |
| 「你昨天几点睡的」 | 单点事实，噪声 | 「你作息大概什么节奏（早睡早起 / 夜猫子 / 不规律）」 |
| 「矩阵乘法你掌握到什么程度」 | 知识点细节，不是能力层 | 「数学你大概到哪一步，能独立算什么层次的问题」 |
| 「你现在在做什么项目，第几周了」 | 项目周报 | 「你手上大致有哪几类项目，做到过什么程度」 |
| 「你觉得自己聪明吗」 | 自评，且属观察面 | 不问（要测就观察） |

落库条目的粒度同样：**一句概括，覆盖一个板块的一个侧面**。用户说了三件事，就写三条，别糊成一条长文本——预算有限，条目要能被单独替换。

## 一轮示例

```
（读完后）这一轮想聊「能力与技能」和「躯体」两面，大概 5 个问题，随时可以喊停。

问：你大概会哪些编程语言，能独立写到哪里？
   A. 基本不会写代码
   B. 会一门，能改别人的脚本
   C. 会两三门，能独立写中小型工具
   D. 多门语言，能设计并维护较大项目
   E. 说不准 / 其它

答：C 吧，Python 和 TS 熟，Rust 只读得懂。

→ memory { action: 'add', track: 'user', scope: 'user-global', facet: '能力与技能',
           tags: ['专业能力', 'questionnaire'],
           text: '会 Python 与 TypeScript，能独立写中小型工具；Rust 只读得懂' }

问：作息大概什么节奏？
   A. 早睡早起   B. 正常但偏晚   C. 夜猫子   D. 很不规律

答：C，一般一两点睡。

→ memory { action: 'add', track: 'user', scope: 'user-global', facet: '躯体',
           tags: ['睡眠与饮食节律', 'questionnaire'],
           text: '作息偏夜猫子，凌晨 1–2 点睡、9 点左右起' }

问：数学上你大概能独立处理到什么层次？
   A. 日常够用   B. 大学基础（微积分、线代）   C. 能读专业论文的数学部分   D. 能吃透并自己推

答：B，够用就行。

→ memory_profile { action: 'set', domain: '数学', level: 5 }

（收尾）这一轮写了 3 条：能力与技能、躯体各一条，数学 5/10（本科）。
         下次可以接着聊「社会与处境」和「经历与轨迹」，那两块现在还是空的。
```
