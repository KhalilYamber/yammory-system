# 题库 · 24 个问卷合法子板块

**读法**：每题标了 `[选择]` 或 `[问答]`。选择题括号里是选项对应的落库含义（档位或类别），写在 `text` 概括里，不要照抄题干。问答题直接听着答，然后概括成一句。

**用法**：一轮挑 1–3 个板块，从对应题目里挑（可改写成用户自己的说法），**一次只问一题**。用户跳过就跳过，别追问。

**先问自己**：这一板块在现有画像里已经有条目了吗？有就先跳过，或只做一次轻量复核。

---

## I · 躯体（facet: `躯体`）

### 生理与健康
- `[选择]` 你身体状态大概属于哪种？A 常年精力充沛 · B 大体健康、偶尔小病 · C 有需要长期管理的慢性问题 · D 体质偏弱、容易累 · E 说不准
- `[问答]` 有没有需要长期留意的事（过敏、旧伤、慢性问题）？—— **用户不愿说就跳过，健康属于可跳过项**。

### 睡眠与饮食节律
- `[选择]` 作息大概什么节奏？A 早睡早起 · B 正常但偏晚 · C 夜猫子 · D 很不规律
- `[选择]` 吃饭主要怎么解决？A 自己做 · B 家里/食堂 · C 外卖为主 · D 不规律，忙起来就忘

### 感官与身体条件
- `[问答]` 有没有影响日常的身体条件（近视度数高、久坐腰背不适、需要戴眼镜/助听之类）？
- `[选择]` 日常体力活动大概什么强度？A 基本不动 · B 走动为主 · C 有固定运动习惯 · D 体力工作/高强度训练

## II · 心智（facet: `心智`）

### 认知能力
- `[选择]` 记东西这件事你更像哪种？A 记得快、忘得也快 · B 记得慢但很牢 · C 靠笔记和检索，不靠脑子 · D 说不准
- `[选择]` 专注力大概什么水平？A 很容易被打断 · B 能专注半小时左右 · C 能连续专注一两小时 · D 进入状态后能扛半天

### 知识与学科水平（→ `memory_profile`，不写条目）
- `[问答]` 先问大类：语言、数理与逻辑、自然科学、工程与技术、人文与社会、艺术与审美、生活与实务、元能力——**哪几类你明显比别人熟？哪几类明显吃力？**
- `[选择]` 再逐个细化（对每个提到的领域问一次）：
  A 听得懂科普 · B 常用概念清楚、能跟上正常讨论 · C 术语自由、能深入细节 · D 行话缩写自由、能讨论边界与不确定
  → 映射 `level`：A = 2–3 · B = 5 · C = 7–8 · D = 9–10；含糊取低不取高
- 只写用户说到的领域，别为凑满 31 项替他打分。

## 收尾要问的一句

一轮结束时可以问：「这轮有没有哪个答案你觉得不准，或者不想留的？」——用户说不准的条目，用 `memory` 的 `replace` 改，或 `remove` 删掉。**画像里留一条错的，比留一处空白更糟。**
