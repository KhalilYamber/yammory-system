# 行为观察（yammory-observe）👁️

从用户**自己的旧发言**里推断「他自己看不清的那几面」，落进 yammory_system 画像。

## 定位：它是布 🧵

采集系统的两条腿：**问卷是针，观察是布**。问卷问「你想要什么」，观察看「你实际怎么做」。落到五个面上，观察是唯一来源——不是补充，是主战场。

| | 问卷 | 观察 |
|---|---|---|
| 拿什么 | 用户此刻的回答 | 用户过去的原话 |
| 强项 | 意愿、偏好、想要什么 | 行为、模式、怎么做的 |
| 落点 | 24 个非 S 板块 | 5 个仅观察面（S 集合） |

**预算纪律**：观察产出的是**推断**，比自陈更贵也更危险。一次至多 3 条，宁少勿多。

## 何时启动

**只由用户主动发起。** 触发不必卡死句式：

- 「观察一下我」「看看你对我了解到什么程度」「从最近的聊天里看看我」
- 「更新一下观察」「yammory observe」

不启动的情形：用户只是在聊天里提到自己；用户没要求而你「觉得该多了解他一点」。**读历史＋推断会占真实上下文，默认不自动跑**——用户没开口就不动。

用户中途喊停（「够了」「先到这」），立刻停，把已确认的写进去，不追问。

## 一轮的形状

```
scan 取切片（只读）→ 读证据 → 推断（≤3 条，每条附原话）
     → 把握为「低」的直接丢 → commit（一次审批 ＋ 一次原子写）
     → 报告：写了哪些面、下次该往哪看
```

### 第 1 步：scan 取切片

```
memory_observe { action: 'scan', days: 14 }
```

默认 14 天 / 8 个会话 / 每会话 12 条 / 单条 400 字符 / 总 12000 字符。**没有 sessionId 入参**——你只能说「最近 N 天」，不能点名某个会话。这是刻意的：插件只允许读与当前会话 `cwd` 精确相等的历史（没有 `cwd` 时只读当前会话自己）。

切片**只含用户本人的发言**。系统注入的伪消息（运行时上下文、AGENTS.md、skill 目录、goal 轮次、子代理通知）已在插件侧过滤，结果里以 `injected` 计数报出——你不会把它们误当证据。

**先读结果里的账单，再读切片**：

| 字段 | 意思 | 你该怎么用 |
|---|---|---|
| `covered` / `budget` | 真进了切片的会话数、条数、字符数 | 判断证据密度 |
| `uncovered.sessions` / `.days` | **没看到**的会话数与天数 | 到顶时切片只是局部，别下全局结论 |
| `scanned.injected` | 挡下的伪发言条数 | 确认过滤生效（正常会有不少） |
| `selfOnly` | `true` = 本会话没有 cwd，只读了自己 | 证据面窄，结论要更保守 |
| `clamped` | 被夹到硬上限的入参 | 说明你要的量超过闸门，不是它没给 |

`uncovered` 不为空时，**报告里要告诉用户这次没看全**，并给出下次的窗口起点（`window.from`）。观察是增量的：下次从更早的窗口继续，不必每次从头看。

### 第 2 步：推断

提示词见下节「推断纪律」。核心只有一句：**每条结论必须附一处用户原话**，找不到就不写。

### 第 3 步：commit 落库

```
memory_observe {
  action: 'commit',
  entries: [{
    face: '思维方式与思辨',        // 五个观察面之一，或「校正」
    text: '被追问时会先复述约束再动手',   // 一句行为描述，不带评价
    evidence: '“先把方案读完再改代码”（09-13 那次）',
    confidence: '高'              // 高 | 中；「低」会被拒绝
  }]
}
```

- **一次 commit 一次审批 ＋ 一次原子写**：1..8 条一起过门，不会逐条烦人。
- 条目自动带 `source: observation`、`facet`（面映射到七面）与 `tags`（子板块 ＋ `observation` ＋ 日期）。
- 用户在设置里把粒度键 `source:observation` 改成 `auto` 即可免审批；改成 `off` 则整条通道被拒。**不要试图绕过审批**，被拒就如实说哪条没写进去，不换措辞重试。
- 该层（user/user-global）有硬字符预算；超了整批失败并给出当前用量。**先整合旧条目再重试**，绝不截断内容硬塞。

### 第 4 步：报告

给用户一句话：这次写了几个面、几条、把握如何；哪些没写（以及为什么）；下次可以从哪个窗口/哪几个面接着看。

**不要复述用户原话，也不要给「人格总结」。** 观察的产出是行为描述，不是判决书。

## 推断纪律

```text
# 任务

你在观察一位长期用户，从他的真实发言里推断「他自己看不清的那几面」。
输入是一段会话历史切片（只有他本人的发言，已按时间窗采样）。

# 只写有证据的

每一条结论必须附一处原话片段作为证据。找不到原话，就不写。
宁可写 0 条，不写没把握的第 1 条。0 条是合法输出。

一次观察最多 3 条。超过 3 条说明你在凑数。

# 禁止人格贴标签

不写人格类型标签（MBTI、九型、大五、依恋类型等一概不写）。
不写诊断（抑郁、焦虑障碍、ADHD 等一概不写）。
不写评价性人格判断（「偏执」「自恋」「情商低」一概不写）。

可以写的是：他在什么情境下做了什么、怎么做的、反复出现的模式是什么。
把「他是 X 型人」换成「他在 Y 情境下会做 Z，出现过 N 次」。

# 五个观察面

1. 思维方式与思辨 —— 他怎么拆问题、怎么用证据、什么时候改变看法
2. 人格特质 —— 面对困难与不确定时的稳定反应（不是性格类型）
3. 情绪模式与心理强度 —— 什么触发他的情绪、他怎么处理、恢复要多快
4. 自我认知 —— 他怎么说自己，以及他说的与做的是否一致（落差写下来）
5. 决策与行动风格 —— 他什么时候果断、什么时候拖延、靠什么拍板

不属于这五面的结论，只在证据非常明确时写，并且标注为「校正」。

# 敏感红线

不主动提取：健康状况与疾病、性取向、宗教与政治立场、精确财务数字、精确住址与证件号。
他明确说过「记住这个」的除外。
涉及上述内容时，跳过不写，不解释为什么跳过。

# 输出

对每条结论给出：
- 面（五个之一，或「校正」）
- 结论（一句话，行为描述，不带评价）
- 证据（原话片段，加会话标识与大致时间）
- 把握（高 / 中 / 低；低的不写）

低把握的直接丢弃，不要输出。
```

## 证据门槛（比问卷严）

一条结论要落库，至少要满足其中一条：

| 门槛 | 说明 |
|---|---|
| 同一结论在本次切片里有 **≥ 2 处**证据 | 一次是巧合，两次才是模式 |
| 同一结论跨 **≥ 2 场会话**出现 | 场合变了、行为没变 |
| 用户**明确自我陈述** | 那属于自陈，照常记，但标为自陈来源 |

只出现一次、且不是用户主动说的，**不写**。

## 面 ↔ 顶层对照（写 `face` 用）

| `face` | 落到七面 | 观察什么 |
|---|---|---|
| 思维方式与思辨 | 心智 | 拆问题的顺序、用证据的方式、改主意的触发点 |
| 人格特质 | 心智 | 面对困难与不确定的稳定反应（不是性格类型） |
| 情绪模式与心理强度 | 心智 | 触发点、处理方式、恢复速度 |
| 自我认知 | 价值与意愿 | 他怎么说自己，说的与做的是否一致 |
| 决策与行动风格 | 行为与习惯 | 何时果断、何时拖延、靠什么拍板 |
| 校正 | 七面之一（**必须自己填 `facet`**） | 五面之外的强证据结论；与既有条目**并存**，不删旧的 |

细节与例句见 [`references/observation-facets.md`](./references/observation-facets.md)。

## 与问卷的边界：分面裁决

两边都碰到同一个面时，**分面裁决**：

| 冲突的面 | 听谁 |
|---|---|
| 能力类（你能做什么） | 听**观察** |
| 意愿偏好类（你想要什么、喜不喜欢） | 听**自陈** |
| 落差类（想做却没做） | **两条都留**——落差本身就是最值钱的画像 |

冲突时**不删、只标注来源与时间**。观察与问卷的条目并存，让模型自己看见落差。

## 口径红线

| 禁止 | 改成 |
|---|---|
| 「他是 INTP / 九型 5 号」 | 「他遇到开放问题时先列可能性再收敛」 |
| 「他有点焦虑」 | 「任务被打断时他会先确认边界再继续」 |
| 「他情商不高」 | 「他在对方情绪明显时会先把话题拉回事实」 |
| 「他经常熬夜，作息紊乱」 | 睡眠作息属躯体面，且非本次证据重点 → 不写 |
| 搬运原话当条目 | 概括成「情境 → 行为 → 频次」 |

条目仍是**周级、能力层的概括**：一条一个意思，可 2–3 句。观察自带证据，所以比问卷条目长一点是正常的。
