# 观察面手册（references/observation-facets.md）

供 `yammory-observe` skill 按需加载。这里放**判据与例句**：什么算证据、什么算贴标签、落库长什么样。

## 一、为什么这五个面只有观察能拿

S 判据：**自陈不可靠 ∪ 主观性强**（`施工清单.md` 第三节）。五个面逐条：

| 面 | 为什么自陈不可靠 |
|---|---|
| 思维方式与思辨 | 自评「我逻辑好」是最不可靠的一类自陈——思维盲区恰恰是看不见的那部分 |
| 人格特质 | 人看不清自己的气质与韧性，尤其在压力下 |
| 情绪模式与心理强度 | 身在情绪里，看不见自己的模式；恢复速度更是旁观者清 |
| 自我认知（优缺点、盲区） | 自陈不可靠的典型：自评偏差本身就是待观察对象 |
| 决策与行动风格 | 人对「自己怎么决策」的叙述常与行为相反 |

另外 24 个子板块归问卷（🔵 = 问卷 ＋ 观察）；观察只在**证据非常明确**时补充，且优先作「校正」。

## 二、五个面各自看什么

### 1. 思维方式与思辨 → `facet: 心智`

看**过程**，不看结论对错。

- 拆问题：先分类还是先找反例？先要约束还是先要方案？
- 用证据：凭印象还是要求出处？被反驳时改结论还是改措辞？
- 改主意：什么条件下他会说「我错了」？还是绕着走？

可写：「被指出问题时他会先要证据出处，再决定改不改（09-13、09-12 两次）」
不可写：「他逻辑性强」

### 2. 人格特质 → `facet: 心智`

看**困难与不确定下的稳定反应**。这是行为层，不是类型学。

- 卡住时：硬扛、换路、还是求助？
- 不确定时：先试探一步，还是先要完整信息？
- 被否定时：反问、沉默、还是立刻修正？

可写：「连续两轮没进展时他会换实现路径而不是继续调参」
不可写：「他有韧性」「他是完美主义」

### 3. 情绪模式与心理强度 → `facet: 心智`

看**触发 → 处理 → 恢复**三段。

- 触发点：什么让他语气变短、反复追问、或突然换话题？
- 处理方式：说破、绕开、还是转去做别的？
- 恢复：多久回到正常节奏？（这是自陈最不准的一段）

可写：「同一问题问第二遍时他会先确认是不是自己没讲清，语气不变」
不可写：「他脾气好」「他有点焦虑」

### 4. 自我认知 → `facet: 价值与意愿`

看**他说的**与**他做的**是否一致，**落差写下来**。

- 自称的水平 vs 实际交付
- 自称的习惯 vs 行为痕迹
- 自评的偏好 vs 实际选择

可写：「自评『我一般吧』，同期却独立交付了两个开源项目（落差：自评偏低）」
不可写：「他自卑」

落差条目与问卷条目**并存**，不覆盖——落差是最值钱的画像。

### 5. 决策与行动风格 → `facet: 行为与习惯`

看**拍板的依据与时机**。

- 果断区：哪些事他一句话就定？
- 拖延区：哪些事他反复问、反复改？
- 依据：数据、直觉、还是别人的确认？

可写：「涉及不可逆操作时他会先要一次复核，可逆操作直接做」
不可写：「他优柔寡断」

## 三、校正（五面之外的强证据）

`face: '校正'` ＋ 必填 `facet`（七面之一）。用在两处：

1. 观察补充问卷够不着的**非 S 面**事实（例：`facet: '能力与技能'`，证据是他实际交付的东西）；
2. 观察与自陈**明显冲突**、且行为证据压倒性（例：自评「数学只到本科」，却连续用矩阵推导并发现错误）。

两条纪律：

- 与既有条目**并存**，不删旧条目（覆盖与仲裁留给 S5）；
- 条目文本自带 `[观察 日期]` 前缀与证据，读者一眼能看出这是推断而非自陈。

## 四、证据门槛与反例

落库前逐条过：

| 检查 | 通过条件 |
|---|---|
| 有原话吗 | 能引出一段用户自己的话（不是你的转述） |
| 出现几次 | 本次 ≥ 2 处，或跨 ≥ 2 场会话，或是用户主动自陈 |
| 是行为吗 | 句子里有「在什么情况下做了什么」，没有形容词化的人格判断 |
| 越线了吗 | 不涉健康/性取向/宗教政治/精确财务/住址证件 |
| 把握够吗 | 高或中；低的一律丢 |

反例四连（都是常见错法）：

| 错法 | 为什么错 | 改成 |
|---|---|---|
| 「他是 INTP」 | 类型标签，且无法证伪 | 删，或改成具体情境下的行为 |
| 「他逻辑很好」 | 形容词评价，无情境无频次 | 「他要求先看证据再下结论，出现过 3 次」 |
| 「他昨天很晚还在改代码」 | 单点流水，噪声 | 不写；作息另有其面，且需多次证据 |
| 「他不想聊这个话题」 | 从沉默推意愿，属猜心 | 不写；除非他明说了 |

## 五、条目长什么样

落库条目（由 `memory_observe commit` 组装，你只提供 `text` 与 `evidence`）：

```
[观察 2026-09-13] 被追问时会先复述约束再动手
证据：“先把方案读完再改代码”（session-037db80b，09-13）
```

- `text`：**一句话**，情境 ＋ 行为（＋ 频次更好）。
- `evidence`：原话片段 ＋ 会话标识与大致时间。
- `tags`：自动带 `['<面>', 'observation', 'YYYY-MM-DD']`，可另加短标签。
- `facet`：五个面自动映射（见 SKILL.md 对照表）；`校正` 需自己填。
- `source`：固定 `observation`（工具锚死，不由你传）。

审批界面上人看到的就是这条文本（含证据），所以**证据写得越具体，越容易被放行**。
